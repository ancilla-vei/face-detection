Face Detection using OpenCV

A simple Computer Vision project that detects human faces in an image using Python and OpenCV using the Haar Cascade Classifier.

Features
Detects faces from an image
Draws rectangles around detected faces
Beginner-friendly OpenCV project
Uses Haar Cascade for face detection
Technologies Used
Python
OpenCV
Haar Cascade Classifier
Project Structure
├── facedetection.py
├── image1.jpg
├── haarcascade_frontalface_default.xml
└── README.md
How to Run
Install OpenCV
pip install opencv-python
Run the project
python facedetection.py
Output

The program detects faces in the image and highlights them with rectangles.
